# SecondBox v0.4.5

SecondBox v0.4.5 repairs automatic guest-network selection in the guided single-host installer.

## Fixed

- Guided installation now preserves `172.30.0.0/24` and `172.31.0.0/24` as preferred guest bridge networks, then deterministically searches every remaining RFC1918 `/24` until it finds one that does not overlap an observed host route. The v0.4.4 selector stopped after the two preferred networks, so a host using both for Docker, VPN, or another local bridge failed before plan review despite having other private address space available.
- An explicit operator-supplied guest CIDR still fails when it overlaps an observed route; only automatic selection advances to another candidate. If all RFC1918 space is genuinely covered, the installer reports that exhaustion directly.

No database, public API, Runner protocol, guest, Profile, or microVM-bundle change is involved.

## Download and install

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/latest/download/install.sh | sh
```

Standalone binaries and SDKs use version `0.4.5` and tag `v0.4.5`.
