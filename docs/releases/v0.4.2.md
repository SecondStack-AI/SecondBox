# SecondBox v0.4.2

SecondBox v0.4.2 supersedes the unpublished v0.4.0 and v0.4.1 tags. It contains the guided single-host installer and CLI presentation release described in the [v0.4.0 notes](v0.4.0.md), plus both qualification-driver fixes found while exercising the release on a real workstation.

## Fixed

- Installer qualification selects a non-overlapping `/24` from the complete RFC1918 address space, as described in the [v0.4.1 notes](v0.4.1.md).
- The qualification driver assigns a guest mode before deriving its domain and workspace names. The previous combined Bash `local` declaration expanded the derived values while `mode` was still unset, so strict-shell execution stopped before creating the first VM.

No deployment, database, public API, Runner protocol, guest, Profile, or microVM-bundle change is involved. Existing v0.3.1 deployments follow the compatibility and upgrade guidance in the v0.4.0 notes.

## Download and install

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/latest/download/install.sh | sh
```

Standalone binaries and SDKs use version `0.4.2` and tag `v0.4.2`.
