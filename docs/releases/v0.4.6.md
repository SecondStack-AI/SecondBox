# SecondBox v0.4.6

SecondBox v0.4.6 lets the guided single-host installer safely upgrade an older SecondBox CLI installation.

## Fixed

- Before downloading release images or extracting the microVM bundle, guided installation now validates the reviewed `secondbox`, `secondbox-deploy`, and CLI configuration destinations. An executable is eligible for atomic replacement only when its embedded Go build identity names the exact corresponding SecondBox command, and an existing configuration is eligible only when it is a protected, strictly decoded SecondBox session document.
- Existing files that are unrelated, malformed, unexpectedly owned, or otherwise outside that narrow upgrade policy remain untouched and stop the operation before expensive release materialization. An interrupted binary upgrade resumes only by adopting a target whose digest exactly matches the accepted release.

This corrects v0.4.5 installations that stopped after artifact materialization with `refusing to adopt pre-existing binary` when an older SecondBox CLI was already installed. Resume the recorded operation with the v0.4.6 `secondbox-deploy` binary; already verified and materialized release artifacts are reused.

No database, public API, Runner protocol, guest, Profile, or microVM-bundle change is involved.

## Download and install

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/latest/download/install.sh | sh
```

Standalone binaries and SDKs use version `0.4.6` and tag `v0.4.6`.
