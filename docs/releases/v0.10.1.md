# SecondBox v0.10.1

SecondBox v0.10.1 fixes an attributed execution relay failure: an HTTP client
closing or resetting one connection could terminate the entire execution gateway.
Subsequent requests in the same command now retain their authority and continue
normally, while gateway failure, cancellation, expiry, and unexpected relay errors
still stop forwarding ([#125](https://github.com/SecondStack-AI/SecondBox/pull/125)).

This patch preserves the v0.10.0 database, Runner protocol, and runtime/toolchain
asset identities. It was qualified on Firecracker, the gVisor host and Kubernetes
pod suites, and all guided installer modes with reboot recovery at commit
`5739d4630ae8408aae071b9095c7c1e1dad56913`.

## Upgrade

Guided installations follow the ordinary coordinated update procedure; the guided
updater applies only to completed guided installations.

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/download/v0.10.1/install.sh | sh
npm install @secondstack-ai/secondbox@0.10.1
go get github.com/SecondStack-AI/SecondBox@v0.10.1
```
