# SecondBox v0.4.3

SecondBox v0.4.3 supersedes the unpublished v0.4.0, v0.4.1, and v0.4.2 tags. It contains the guided single-host installer and CLI presentation release described in the [v0.4.0 notes](v0.4.0.md), both installer qualification-driver fixes described in the [v0.4.1](v0.4.1.md) and [v0.4.2](v0.4.2.md) notes, and the Runner control-session fix found during final real-host qualification.

## Fixed

- A Runner control connection no longer fails after 256 registration, heartbeat, lifecycle, and Workspace messages. The control plane retains the latest 256 message IDs as an in-memory fast path and sends older replays through PostgreSQL's persisted duplicate and monotonic-sequence checks. Long-lived sessions remain bounded in memory without turning the bound into a connection lifetime.

No database migration, public API schema change, Runner protocol schema change, guest change, Profile change, or microVM-bundle change is involved. Existing v0.3.1 deployments follow the compatibility and upgrade guidance in the v0.4.0 notes.

## Download and install

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/latest/download/install.sh | sh
```

Standalone binaries and SDKs use version `0.4.3` and tag `v0.4.3`.
