# SecondBox v0.26.1

v0.26.1 is the first published release of the changes described in the
[v0.26.0 notes](v0.26.0.md): gVisor Runners from `secondbox-deploy`, the
required `compute_backend` in every `[[runners]]` declaration, the same-host
`storage_admission_mode` fix, the installer sizing options, and the
attributed-execution placement fix. Follow the v0.26.0 deployment boundary
when updating.

v0.26.0 was tagged on `fc30ce2`, but its release staging smoke still ran
`secondbox-deploy runner-template` without the now-required `--backend` and
failed on both architectures before any artifact was published. v0.26.0 is
retracted in `go.mod`; use v0.26.1. Release staging now smokes the Firecracker
and gVisor Runner templates.

Install the TypeScript SDK with `npm install @secondstack-ai/secondbox@0.26.1`.
The Go module is `github.com/SecondStack-AI/SecondBox@v0.26.1`.
