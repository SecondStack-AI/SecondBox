# SecondBox v0.7.1

SecondBox v0.7.1 supersedes v0.7.0 because the public Go module proxy cached the `v0.7.0` tag from an intermediate release-preparation commit. The `go.mod` file now retracts `v0.7.0`; use `github.com/SecondStack-AI/SecondBox@v0.7.1`.

For Go module users, v0.7.1 includes the final v0.7.0 qualification fixes that were absent from the proxy's cached commit: exact v0.6.0 quota decoding, strict source-era recorded deployment-manifest decoding, release-waiver authentication, host-platform evidence, and cold-boot DNS setup. Relative to the final GitHub v0.7.0 distribution, this patch preserves the public API, database migrations, Runner and guest protocol windows, deployment topology, standard resource specifications, and signed Firecracker microVM bundle. It rebuilds and republishes every coordinated artifact from one immutable, qualified v0.7.1 source commit. Read the [v0.7.0 release notes](v0.7.0.md) for the full feature, compatibility, and migration details.

## Upgrade

Use v0.7.1 for both new installations and upgrades. For a completed guided v0.6.0 installation, take and verify a PostgreSQL backup, stop every Sandbox, then run the v0.7.1 bootstrap:

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/download/v0.7.1/install.sh \
  | sh -s -- update --check /absolute/path/to/secondbox-install-operation
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/download/v0.7.1/install.sh \
  | sh -s -- update /absolute/path/to/secondbox-install-operation
```

Completed guided v0.7.0 installations can use the same v0.7.1 `update --check` and `update` commands. The update preserves PostgreSQL data, deployment authority, Runner identity, Workspaces, Snapshots, topology, and Compose volumes.

Install SDKs at the coordinated v0.7.1 version:

```sh
npm install @secondstack-ai/secondbox@0.7.1
go get github.com/SecondStack-AI/SecondBox@v0.7.1
```
