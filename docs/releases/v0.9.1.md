# SecondBox v0.9.1

v0.9.0 was tagged but retracted before publication: its installer qualification driver still required the v5 artifact manifest. Use v0.9.1.

SecondBox v0.9.1 makes the gVisor backend a supported backend for Linux amd64 hosts without KVM, Kubernetes nodes included, and distributes it with every release. The Firecracker backend, its published bundle, and its trust anchor are unchanged from v0.6.0.

Two images join the published set: `ghcr.io/secondstack-ai/secondbox/runner-gvisor` (the runner, the guest agent, and the pinned `runsc`) and `ghcr.io/secondstack-ai/secondbox/gvisor-artifacts`, a transport carrying the prepared flat root under `/secondbox-runner-gvisor/rootfs`, `runsc` and the guest agent under `/secondbox-runner-gvisor/bin`, and the backend materialization. The materialization is also the release file `secondbox-0.9.1-gvisor-materialization.json`. Both artifacts are built from the repository and its digest-pinned bases; staging needs no operator-assembled gVisor inputs.

The artifact manifest schema advances to `secondbox.release/artifact-manifest/v6`: a `gvisor` section records the runner and artifact image digests, the materialization digest, the flat-root digest, the `runsc` release, and the gVisor host and pod scenario evidence, both bound to the release commit and produced on a host without KVM. Release verification fetches the materialization and both evidence files, checks their digests, and confirms the materialization agrees with the recorded identities. Recorded v5 manifests of earlier releases stay readable by the updater.

The guided installer still deploys Firecracker; `secondbox-deploy --backend gvisor` remains a read-only preflight. gVisor deployments are composed by Kubernetes operators from the released images, as the [gVisor runtime](../operations/gvisor-runtime.md) and [Kubernetes boundary](../operations/kubernetes-boundary.md) documents describe.

Install SDKs at the coordinated v0.9.1 version:

```sh
npm install @secondstack-ai/secondbox@0.9.1
go get github.com/SecondStack-AI/SecondBox@v0.9.1
```
