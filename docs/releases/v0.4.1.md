# SecondBox v0.4.1

SecondBox v0.4.1 supersedes the unpublished v0.4.0 tag. It contains the guided single-host installer and CLI presentation release described in the [v0.4.0 notes](v0.4.0.md), plus a qualification-driver portability fix discovered while exercising the release on a Docker-heavy workstation.

## Fixed

Installer qualification now selects a non-overlapping `/24` from the complete RFC1918 address space. The original driver considered only eleven networks inside `192.168.240.0/20`; Docker had legitimately allocated that block on the qualification host, so the mandatory release gate stopped before creating a VM. The expanded allocator still refuses every subnet overlapping a host route and fails closed when no private `/24` remains.

No deployment, database, public API, Runner protocol, guest, Profile, or microVM-bundle change is involved. Existing v0.3.1 deployments follow the compatibility and upgrade guidance in the v0.4.0 notes.

## Download and install

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/latest/download/install.sh | sh
```

Standalone binaries and SDKs use version `0.4.1` and tag `v0.4.1`.
