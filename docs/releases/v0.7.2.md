# SecondBox v0.7.2

SecondBox v0.7.2 removes the two operator workarounds that blocked normal SecondStack use of the experimental gVisor backend. gVisor now consumes the complete Runner network-policy contract, including explicit logical gateway authorization, and the Runner ships a supported flat-root preparation command that materializes and validates every required bind destination before the root identity is pinned.

Firecracker remains the only supported production backend. This patch does not change the public API, database schema, Runner protocol, guest protocol, standard resource specifications, or signed Firecracker microVM bundle. The published Firecracker bundle and trust anchor are unchanged from v0.6.0.

## Upgrade

Guided Firecracker installations can upgrade from v0.6.0, v0.7.0, or v0.7.1 with the v0.7.2 bootstrap. Take and verify a PostgreSQL backup, stop every Sandbox, and run the preflight before the mutating update:

```sh
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/download/v0.7.2/install.sh \
  | sh -s -- update --check /absolute/path/to/secondbox-install-operation
curl -fsSL https://github.com/SecondStack-AI/SecondBox/releases/download/v0.7.2/install.sh \
  | sh -s -- update /absolute/path/to/secondbox-install-operation
```

Existing experimental gVisor deployments require a coordinated materialization update. Stop the Runner and set all six generic network-policy variables explicitly:

- `SECONDBOX_RUNNER_NETWORK_POLICY_MAX_DNS_PINS`
- `SECONDBOX_RUNNER_NETWORK_POLICY_MAX_DNS_TTL`
- `SECONDBOX_RUNNER_NETWORK_POLICY_RUNNER_ADDRESSES`
- `SECONDBOX_RUNNER_NETWORK_POLICY_MANAGEMENT_CIDRS`
- `SECONDBOX_RUNNER_NETWORK_POLICY_RUNNER_GATEWAYS`
- `SECONDBOX_RUNNER_NETWORK_POLICY_DNS_UPSTREAM`

Run `secondbox-prepare-gvisor-flat-root` against each extracted OCI flat root before calculating its digest. Then recompute `flatRootDigest`, update and redigest the materialization manifest, repin the Runner's materialization digest, revise affected Profiles to the new execution-asset identity, and restart the Runner. The preparer creates only missing required bind destinations and rejects symlinks or incompatible nodes; the Runner rejects roots that do not satisfy the contract before advertising readiness.

See [experimental gVisor runtime](../operations/gvisor-runtime.md) for the complete environment and preparation procedure.

Install SDKs at the coordinated v0.7.2 version:

```sh
npm install @secondstack-ai/secondbox@0.7.2
go get github.com/SecondStack-AI/SecondBox@v0.7.2
```
