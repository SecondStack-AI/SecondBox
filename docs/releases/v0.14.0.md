# SecondBox v0.14.0

## Deployment boundary

This release requires a fresh database and a separate Runner storage root.
The unlimited Snapshot retention fix changes the initial migration checksum;
an existing database, including one initialized by v0.13.0, fails the migration
checksum check. There is no in-place migration or Workspace adoption path.
Keep the previous deployment and its state together until its owners retire
their Sandboxes. Rollback uses that deployment's original database, storage,
signed assets, and credentials. See the [deployment procedure](../operations/deployment.md).

The signed `secondbox-0.12.0` Firecracker bundle and its trust anchor remain
unchanged. Their identities are recorded in the [v0.12.0 notes](v0.12.0.md).

## Workspace storage accounting

Sandbox reads and lists expose optional `workspace.storageObservation.exclusiveBytes`
beside `allocatedBytes`. Exclusive bytes measure image extents unshared with
templates, Snapshots, or other Workspaces, rather than guest filesystem usage.
Their sum is a physical lower bound; summing allocated bytes double-counts
shared extents.

The Runner probes metadata without mounting or writing the image. One bounded
background scan keeps slow FIEMAP calls off heartbeat and command paths.
Unsupported FIEMAP, incomplete maps, unstable allocation, unshared encoded or
compressed extents, and probe errors leave exclusive bytes absent with a
distinct `exclusiveReason`, preserving allocated bytes. See the
[observation semantics](../operations/observability-and-diagnostics.md).

## Inventory and controller APIs

- Sandbox listings accept repeated `state` and `id` filters alongside metadata.
  Filters intersect and remain bound to pagination cursors. Go and TypeScript
  list options expose the new fields.
- Missing Workspace files return `file_not_found`. Missing Sandboxes, unavailable
  compute, and generation fencing retain distinct meanings.
- Subject quota updates include an optional `quotaObservation` computed in the
  mutation transaction. Idempotent replay preserves that original observation.
- TypeScript adds Subject and ApplicationAuthority management helpers and tenant
  usage reads, including revision and idempotency handling.

See the [API conventions](../design/api-conventions.md) for request semantics.

## Snapshot retention

Snapshots with unlimited retention now persist without an expiry and remain
visible through reads and lists. Finite retention continues to expire normally.

## Distribution

This release uses the default release tier: Linux amd64 container images,
Firecracker and local gVisor qualification, and the Btrfs-image installer guest.
CLI and deployment binaries ship for Linux and macOS on amd64 and arm64.

Install the TypeScript SDK with `npm install @secondstack-ai/secondbox@0.14.0`.
The Go module is `github.com/SecondStack-AI/SecondBox@v0.14.0`.
